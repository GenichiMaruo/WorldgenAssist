# Worldgen Assist

![Worldgen Assist のアイコン](src/main/resources/icon.png)

[English](README.md) | [日本語](README.ja.md)

Worldgen Assist は、プレイヤーの PC がサーバーの新しい地形の計算を手伝う
Fabric・Forge・NeoForge 対応 MOD です。探索時の地形生成の負担を分担しつつ、ワールドの管理は
サーバーに残します。β版は、信頼できる参加者が支援を有効にして遊ぶ専用サーバー向けです。

対象となる Overworld・Nether・End の新規チャンクが必要になると、MOD は同じプレイヤーの
クライアントに地形の形を決める計算の一部を依頼できます。サーバーは結果を検査し、
通常の vanilla 生成を自ら続行します。鉱石、構造物、流体、ブロック配置、保存、
およびゲームプレイに関わるすべてのワールド状態はサーバー権限のままです。

## 現在のβ版

**0.1.0-beta.1+mc26.3** は Minecraft 26.3、Java 25 向けです。サーバーと参加クライアントに、
使用するローダーの配布用 JAR を導入してください。共有プロトコルは14、ネイティブ通信は6です。
支援・ネイティブ版の直接受付・まとめ送りは既定で無効です。完全な地形生成の委託には
対応条件を満たすバニラのオーバーワールドを使い、参加者にワールドのシードを開示します。

過去の Fabric 測定では、弱い専用サーバー（i7-7700K）に、別の強い PC（i7-12700K）上の
2クライアントが距離32で接続しました。同じ MOD・同じ生成設定で支援の有無を切り替え、
3領域を実行順を入れ替えて計6組比較すると、**チャンクの生成完了までの時間は中央値で
20.93%短縮**しました。必要なチャンクの受信は21.20%短縮、サーバーのCPU時間は19.63%減少し、
遅い側のサーバーtick時間（95パーセンタイル）は8.95%増えました。受信の計測は描画前に終了します。

β版の検証項目は、同じワールドでの再起動、2人による60分のクリエイティブ飛行、飛行前後の
サバイバル操作、保存後のプレイヤー・ブロック・照明です。ローダー別の結果を掲載しています。
[導入案内](docs/INSTALL.ja.md)・[β版の変更内容](docs/releases/v0.1.0-beta.1+mc26.3.md)・
[β版の検証記録](docs/releases/v0.1.0-beta.1+mc26.3-verification.md)

alpha.9の別の比較では、支援を有効にしたまま任意の直接受付を使うと、往復待ち時間は
Forgeで21.28%、NeoForgeで17.26%短縮しました。生成完了はそれぞれ2.92%・0.20%短縮し、
ForgeのサーバーCPU時間は9.99%増加しました。
[alpha.9の変更内容](docs/releases/v0.1.0-alpha.9+mc26.3.md)・[当時の検証記録](docs/releases/v0.1.0-alpha.9+mc26.3-verification.md)

**0.1.0-alpha.3+mc26.2** では、vanilla の Overworld・Nether・End における
プレイヤー本人所有の支援、ゲーム内設定画面、正しさと性能を一括検証するコマンドを
追加しました。測定した12条件では支援ありの処理量が通常生成より低く、

再接続後、保存したサーバー設定はサーバー再起動後に反映されます。リモートからの

各プレイヤーは自分の表示範囲内の地形計算を同時に支援できます。
範囲が重なるチャンクは1人に割り当て、既定の全体上限は8ジョブです。alpha.6 は
1人あたり1ジョブから開始し、クライアントの処理能力に応じて最大4ジョブまで調整します。
クライアントの計算スレッドは既定で2本です。[複数プレイヤー対応と検証状況](docs/MULTIPLAYER_SUPPORT.md)を
参照してください。

これらのアルファ版は、信頼できる参加者との条件を限定した試用向けでした。
リモート支援は既定で無効で、速度向上も保証しません。実装済みの
リモート経路は、明示的に信頼した参加者、新規生成の vanilla 互換
Overworld・Nether・End、対象条件を満たす新しい地形に限定されています。
alpha.5 は両側で利用できる互換 vanilla ノイズ設定の追加ディメンションと、同じ vanilla
ノイズ生成器への委譲を明示するラッパーを実験的に受け入れます。以前の Fabric 追加
ディメンション検証は成功していますが、任意の独自生成アルゴリズムやクライアントに
存在しないノイズ定義は対象外です。敵対的な公開サーバーや他プレイヤーへの計算共有にも
対応しません。

## 実装されていること

- クライアントとサーバーは別のジェネレーターを作るのではなく、地形密度の計算を
  分担します。
- サーバーは上限付きの入出力検査と、任意で独立したビット完全一致の検証を行って
  から結果を受け入れます。
- タイムアウト、切断、不正な結果、リロード、利用できないワーカーでは、通常の
  サーバー内生成へフォールバックします。
- 旧来の trusted-raw 経路には、可逆 RAW/DEFLATE 圧縮、上限付きのコンテキスト対応
  キャッシュ、プレイヤー所有の予測があります。キャッシュと予測は、下記の公開
  フィクスチャには含まれません。

alpha.3 のチェックポイントでは Java 25.0.4 で **264 テスト / 58 スイート**を
実行しました。その後の設定画面の修正は、対象を絞ったテストと配布ビルドで確認し、
全テストは再実行していません。3組の全ディメンション正しさ検証では、共有
NOISE ダイジェスト **4,284個**が一致しました。検証ログにはオフライン認証・
Realms エラーが残り、通常生成サーバーの終了が時折失敗しました。
これは記載した範囲での機能確認であり、速度向上、プライベート seed の機密性、
公開サーバーでの安全性を証明するものではありません。証拠は英語の
[テスト結果](docs/TEST_RESULTS_LATEST.md)を参照してください。

## 重要なセキュリティ上の区別

2 つの別個の実験経路があります。

| 経路 | 範囲 | セキュリティ上の意味 |
| --- | --- | --- |
| trusted raw-seed モード | 明示的に信頼したクライアントと、使い捨ての制御されたワールド | サーバーが raw seed を送信します。seed を秘匿すべき場面では使わないでください。 |
| 公開 transcript フィクスチャ | すでに公開されている seed `8675309` のみ | 狭いテスト経路です。プライベート seed の機密性は提供しません。 |

raw seed のフィールドを省くだけでは機密性は保証されません。決定論的 transcript は
候補 seed の照合を可能にすることがあります。プライベートワールドでのリモート生成は、
通常のサーバーで有効にする設定ではなく、研究とセキュリティ上の未解決ゲートです。

## 安全な導入

現在の26.3版は[ローダー別の導入案内](docs/INSTALL.ja.md)を参照してください。
以下の説明と対応バージョンは以前の26.2 Fabric版のものです。

同じ **MOD JAR** を Fabric クライアントと
Fabric サーバーの両方に入れてください。`-sources.jar` は、どちらの `mods` フォルダー
にも入れないでください。研究上の制約を理解するまでリモート支援は無効のままにし、
必ず使い捨てのワールドで試してください。

| 必要なもの | バージョン |
| --- | --- |
| Minecraft Java Edition | 26.2 |
| Fabric Loader | 0.19.3 |
| Fabric API | 0.156.0+26.2 |
| Java | 25（25.0.4 で確認） |

MOD を動かす場所には Minecraft、Fabric Loader、Fabric API、Java が必要です。
vanilla クライアントが自動的にワーカーになることはありません。実験的な支援経路では、
両側への導入が必要です。

## FAQ

**サーバーは速くなりますか？** 検証用の弱いサーバーでは、距離32のFabric比較で
6組すべての生成完了が早まりました。効果はハードウェア、通信、設定によります。
比較に使用した設定は[導入案内](docs/INSTALL.ja.md)にあります。

**サバイバルワールドのシードを秘密にできますか？** シードの秘匿が必要な場合は支援を
無効にしてください。26.3版の支援設定ではシードを参加クライアントに送ります。
26.2版の公開フィクスチャは既知のシード `8675309` 専用です。

**クライアントが地形やフィーチャーを決めますか？** クライアントが返すのは途中の
計算結果で、その適用と生成の完了はサーバーが行います。ただし、抜き取り検証は
悪意ある結果をすべて防げる保証ではありません。
