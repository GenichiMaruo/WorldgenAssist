## Evidence and its limits

- The pre-settings-correction `validation-matrix-20260921-012249-436`
  checkpoint passed **264 tests / 58 suites** with zero JUnit failures,
  errors or skips. Local settings smoke passed and screenshots were inspected.
- The selected `validation-matrix-20260921-152005-951` run proved assisted
  application in Overworld (two players), Nether (two players), and End (one
  player); **4,284** shared NOISE digests matched independent vanilla output.
  The Overworld vanilla server did not stop cleanly, so the selected batch
  failed as a whole. Its isolated retry
  `shutdown-overworld-vanilla-p2-20260921-154325-547` passed with safe cleanup.
  The intermittent shutdown issue is still open.
- Twelve matched performance pairs have one excluded warm-up and three measured
  repeats each. The read-only analysis
  `performance-selected-review-20260922-140947-977` reports COMPLETE/zero
  issues, but assisted throughput was lower in all twelve conditions. This is
  descriptive evidence, not a general performance guarantee.
- The runtime/performance JAR hash was
  `3A8D1EB51D81AF204C9CD90DE8F6CC467218429D2FBD133F18D952449182720C`.
  Final settings changes passed six affected suites/20 tests and build in
  `settings-correlation-verification-retry-20260923-182455-047`, then two
  directly affected suites/five tests and build in
  `settings-rate-limit-verification-20260923-182905-264`. Both are clean.
  The two runs cover 21 distinct settings tests. Class comparison found 205
  unchanged classes, three changed settings classes, four added settings
  classes, and none removed; terrain-generation classes did not change.
  No full JUnit or worldgen runtime rerun was made on the final JAR.
- The settings screen was exercised locally; an actual connected remote
  operator/non-operator screen exchange was not rerun after the settings fixes.
  Decision, permission, revision, codec, request-correlation and rate-limit
  behavior have focused tests. Offline client authentication/Realms errors
  remain in retained logs. No error-free-log claim is made.
