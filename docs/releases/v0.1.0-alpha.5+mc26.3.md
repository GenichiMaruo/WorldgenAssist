# Worldgen Assist 0.1.0-alpha.5 — Minecraft 26.3

## 日本語

クライアントの計算能力を新規地形生成に利用する仕組みを改善したアルファ版です。
サーバーが依頼範囲・最終ワールド状態を管理し、参加者は本人の地形密度計算を支援します。

- Minecraft Java Edition **26.3 / Java 25**。Fabric Loader **0.19.5** + Fabric
  API **0.161.0+26.3**、Forge **66.0.3**、NeoForge **26.3.0.13-beta** の
  各導入用 JAR とソース JAR を配布します。`-sources.jar` は導入用ではありません。
- **サーバーと参加クライアントを alpha.5 に揃えてください。** プロトコル4の
  float32密度転送に変更し、非圧縮密度データを従来の半分にしました。
  alpha.4（プロトコル3）とは支援通信できません。
- 生成コンテキストを再利用し、クライアント計算中に検証用サンプルを準備します。
  実際の生成予定を利用した先行計算とキャッシュ、応答時間に合わせた待機、
  複数参加者への公平な割り当てを追加しました。
- クライアントは計算スレッドから返信します。Fabric はサーバーのメインスレッドを
  経由する受信待ちを減らし、最大4依頼のまとめ送りに対応します。
  Forge／NeoForge は個別依頼と従来のサーバー受信経路を維持します。
- 両側に互換ノイズ設定がある追加ディメンションと、vanilla ノイズ生成器を明示的に
  使うカスタムラッパーを実験的に受け入れます。任意の独自生成器への対応ではありません。
- 最新候補の Fabric・Overworld・2人接続の一致検証で、共有 NOISE ダイジェスト
  **1,802件が一致**しました。配布版は3ローダーとも候補 JAR とバージョン情報だけが
  異なり、その他のアーカイブ内容はすべて一致しています。配布版でゲームを再実行した
  検証ではなく、元の候補に紐づく証跡と同一内容の確認です。

### 性能と制限

別PCのサーバーを2論理CPUに制限し、クライアント2台で測定した3回の中央値です。

| 対象9×9範囲の完了時間 | 支援なし | 支援あり |
| --- | ---: | ---: |
| 地形生成（NOISE） | 11.26秒 | 7.45秒 |
| チャンク完成（FULL） | 14.58秒 | 14.84秒 |
| 両クライアントへの到着 | 17.44秒 | 17.80秒 |

地形生成は約34%前倒しできましたが、**プレイヤーの待ち時間短縮は未達成**です。
この測定は前回リリースとの直接比較ではありません。測定中には支援待ちの期限切れに
よる通常生成への切り替えが20件ありました。任意の環境での高速化は保証しません。
最新変更の Forge／NeoForge 実行検証、長時間運用、任意のMODとの互換性は未確認です。

**リモート支援は既定で無効**です。有効化には別の明示設定でワールドシードを参加者へ
開示します。信頼できる参加者と使い捨ての検証ワールド向けです。非公開シードの秘匿性は
未解決で、26.2の公開シード専用 transcript 経路は26.3に含まれません。
添付の日英導入案内・検証記録・`SHA256SUMS.txt` を確認してください。

## English

This alpha improves client-assisted terrain computation while keeping job
assignment, validation and final world state authoritative on the server.

- Requires **Minecraft Java Edition 26.3 / Java 25**. Separate installable and
  source JARs are provided for Fabric **0.19.5** + Fabric API **0.161.0+26.3**,
  Forge **66.0.3**, and NeoForge **26.3.0.13-beta**.
- Upgrade the server and all participating clients to **alpha.5** together.
  Protocol **4** transports exact float32 densities, halving raw density bytes.
  Assistance is incompatible with alpha.4's protocol 3.
- Adds context reuse, authoritative sample preparation during client work,
  observed-generation prefetch, ready-result caching, adaptive waiting and
  fair admission across owners. Clients reply directly from their workers.
- Fabric adds connection-scoped network ingress before the main-thread packet
  queue and optional batches of up to four requests. Forge/NeoForge retain
  individual requests and their previous server receive routes.
- Experimentally admits compatible additional dimensions and explicit vanilla
  noise delegates; arbitrary custom algorithms and client-unavailable noise
  registries are unsupported.
- The latest Fabric Overworld two-owner candidate matched **1,802** shared NOISE
  digests. All three release JARs differ from their saved candidates only in
  version metadata; every other archive entry matches. Runtime evidence retains
  its original candidate identity rather than being relabeled as a final-JAR run.

The selected three-repeat benchmark used a separate server limited to two
logical CPUs and two clients. Median target NOISE-region completion was
**11.26s vanilla / 7.45s assisted**, FULL completion **14.58s / 14.84s**, and
receipt by both clients **17.44s / 17.80s**. **Player wait-time reduction remains
unproven.** This is not a direct comparison with alpha.4. Twenty measured demand
waits fell back to local generation. Latest native-loader runtime, long sessions
and arbitrary mod compatibility are not verified.

Remote assistance is **off by default**. A separate explicit choice discloses
the raw seed to trusted participants. Use disposable test worlds; private-seed
confidentiality remains unresolved. The 26.2 public-seed transcript fixture is
not included. Read the attached installation notes, verification record and
`SHA256SUMS.txt`. Sources JARs are for developers, not installation.
