# Worldgen Assist 0.1.0-alpha.7 — Minecraft 26.3

## 日本語

地形計算の分散範囲を広げ、サーバーの計算量を減らしたアルファ版です。
**大幅な高速化は未達のため、β版にはしていません。**

- Minecraft **26.3 / Java 25**。Fabric **0.19.5** + API **0.161.0+26.3**、
  Forge **66.0.3**、NeoForge **26.3.0.13-beta** の専用JARを配布します。
- 通信プロトコルは **12**。サーバーと参加クライアントを同時に更新してください。
- 明示的に選んだOverworldの完全地形モードでは、地形・表面・洞窟の計算結果を返します。
  サーバーが渡す上限付きの構造物情報により、村などの周辺地形も支援できます。
  構造物・木・鉱石の配置、照明、保存、ゲームプレイはサーバーが管理します。
- 別クライアントによる全体照合を追加しました。各人の最初の2件をサーバーで全計算して
  確認した後、適格な別クライアントがいる場合は全体一致とサーバー側の秘密の1/64抽選を
  使います。通常のサーバー検証は1/8です。途中失敗・世代変更・期限・上限を確認し、
  対応外の場合は通常生成へ戻ります。照合相手もサーバーが割り当てます。
- 不要な依頼の取り消し、既存の生成依存関係の早期観測、バイオーム計算のキャッシュ、
  非同期待機と検証受付の改善を含みます。仮描画は実装していません。

### 実機での結果

弱いサーバーPC（i7-7700K、CPU制限なし）と強いクライアントPC（i7-12700K上で2人分）を
使い、距離32、1回ウォームアップ後に同じ領域を3回ずつ比較しました。両条件とも同じ
サーバー並列生成方式です。以下は**同じ領域ごとの比率の中央値**です。

| 指標 | 支援ありの変化 | 改善回数 |
| --- | ---: | ---: |
| チャンク完成（FULL） | **2.24%短縮** | 3/3 |
| 両クライアントへの到着 | **1.74%短縮** | 3/3 |
| サーバーCPU時間 | **20.53%減少** | 3/3 |
| tick処理時間p95 | **0.32%増加** | 1/3 |

各回10,658生成タスク、各人3,461チャンクの受信を確認しました。受信は描画完了を含みません。
測定順は通常生成→支援で、逆順・長時間運用・他構成での効果は未確認です。
alpha.6との直接比較ではありません。サーバーの計算量は減りましたが、待ち時間の短縮は小幅です。

変更に関係する7テストと3ローダービルドを一括実行しました。通常生成との地形一致は
Fabric **1,813**、Forge **1,971**、NeoForge **2,002**チャンクで不一致0件。
構造物周辺の新しい経路を実際に反映した一致確認も各ローダーで通過しました。
公開JARは検証済みdev.16と**版情報のみ異なる**ことを照合済みです。元の検証を公開JARの
新規実行とは扱いません。詳細とハッシュは添付の検証記録に記載しています。

支援・完全地形・別クライアント照合は既定で無効です。シードを開示する明示設定が必要で、
信頼できる参加者向けです。シード秘匿・悪意ある参加者や共謀への耐性は未解決です。
完全地形モードは対応するvanilla Overworldに限定され、任意の独自生成器は対象外です。
添付の日英導入案内とチェックサムを確認してください。ソースJARは導入用ではありません。

## English

This alpha expands terrain offload and reduces server computation. Substantial
acceleration remains unachieved, so this is **not a beta**.

Requires Minecraft26.3/Java25; separate Fabric0.19.5 + API0.161.0+26.3,
Forge66.0.3 and NeoForge26.3.0.13-beta artifacts. **Protocol12 requires updating
the server and participating clients together.** Explicit complete-terrain mode
returns terrain/surface/carver output for eligible vanilla Overworld contexts,
including bounded server-issued structure shaping. Structures/features/light/
saving/gameplay remain server-owned; there is no provisional rendering.

Optional distinct-client verification compares entire immutable outputs. Both
owners first pass two independent server full audits. With a suitable trusted
peer, private server audit draws use1/64; default server verification uses1/8.
Failures, disconnects, epochs, bounds and guarded final application retain local
fallback. Peer collusion/hostile-client proof and seed secrecy remain unresolved.
Remote/seed disclosure/complete/peer choices remain explicit and off by default.

On an unrestricted weaker i7-7700K server and two clients sharing a stronger
i7-12700K PC, view32/one warmup/three same-region repeats, **median paired
ratios** improved FULL2.24%, receipt1.74%, server CPU20.53%, all three repeats;
tick p95 increased0.32%(only one repeat lower). Both conditions used the same
cooperative backend. Each repeat completed10,658 tasks and3,461 receipts per
owner. Receipt excludes rendering. Vanilla-first order only; not an alpha.6
comparison or a general speed guarantee. CPU distribution improved much more
than completion latency.

Seven affected tests/three builds passed. Fresh matching terrain digests:
Fabric1,813/Forge1,971/NeoForge2,002,zero mismatch,including actual shaped and
peer-approved applications. Native view4 is functional evidence only. Release
packaging verifies that only version metadata differs from tested dev.16;
original runtime identities are retained. Arbitrary generators/mod compatibility
and long sessions remain unverified. Read the attached guides, verification and
checksums; do not install source JARs.
