# Worldgen Assist 0.1.0-alpha.1 — Minecraft 26.2 (Fabric)

## English

First experimental alpha of client-assisted terrain generation. A player's PC
can calculate selected intermediate terrain data for that player's new chunks;
the server retains final world authority and local generation fallback.

- Target: Minecraft Java Edition 26.2, Fabric Loader 0.19.3,
  Fabric API 0.156.0+26.2, Java 25 (tested with 25.0.4).
- Version: `0.1.0-alpha.1+mc26.2`; tag: `v0.1.0-alpha.1+mc26.2`;
  maintenance branch: `mc/26.2`.
- Includes bounded jobs, timeout/cancellation/disconnect fallback and server-side
  result checks. The trusted raw-seed path also has compression, caching and
  player-owned prediction. The public transcript fixture is a separate route.
- Remote work is **disabled by default**. Trusted raw-seed mode discloses the
  seed; the transcript fixture supports only public seed `8675309`.
- No demonstrated speedup, private-seed secrecy, general multiplayer support,
  other-dimension support or hostile-public-server safety is claimed.

Install the normal mod JAR on both client and server, alongside Fabric API.
Do not install the `-sources.jar`. Use a disposable test world, not a private
survival world. Minecraft and dependencies are not bundled.

## 日本語

プレイヤーの PC が新しい地形の計算の一部を手伝う MOD の初期アルファ版です。
そのプレイヤーが必要とするチャンクの中間計算を分担し、最終的なワールド生成と
ローカル生成への切り替えはサーバーが管理します。

- 対応: Minecraft Java Edition 26.2、Fabric Loader 0.19.3、
  Fabric API 0.156.0+26.2、Java 25（25.0.4 で検証）。
- バージョン: `0.1.0-alpha.1+mc26.2`。対応版ごとの管理用に
  `mc/26.2` ブランチと `v0.1.0-alpha.1+mc26.2` タグを使用します。
- ジョブ数の制限、タイムアウト・キャンセル・切断時の通常生成への復帰、
  サーバー側の結果検査を実装しています。trusted raw-seed 経路には圧縮・
  キャッシュ・本人の移動予測もあります。公開 transcript の検証経路とは別です。
- リモート支援は **既定で無効** です。trusted raw-seed モードはシードを開示し、
  transcript の検証経路は公開シード `8675309` 専用です。
- 速度向上、非公開シードの秘匿性、一般的な多人数運用、他ディメンション、
  悪意ある参加者がいる公開サーバーの安全性は保証しません。

通常の MOD JAR と Fabric API をクライアントとサーバーの両方に導入してください。
`-sources.jar` は導入用ではありません。個人のサバイバルワールドではなく、
使い捨てのテストワールドで試してください。本体と依存ソフトは同梱しません。
