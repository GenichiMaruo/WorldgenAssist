# Alpha.2 release verification — 2026-09-14

Version: `0.1.0-alpha.2+mc26.2`, tag `v0.1.0-alpha.2+mc26.2`.
Minecraft Java Edition 26.2, Fabric Loader 0.19.3, Fabric API 0.156.0+26.2,
Java 25 (verified with JDK 25.0.4). No dependency or protocol upgrade.

## Change

Each participating client can assist terrain within its own player's view while
other players assist theirs. Overlapping views select one owner deterministically;
a busy selected owner falls back locally. Default global capacity is eight jobs,
with at most one per owner. Connection replacement, cancellation, quarantine,
cache and prediction identity remain owner-specific. Fabric disconnect callbacks
are handed to the server thread; stale disconnects cannot remove a replacement
player's state. Timeout quarantine immediately blocks that owner's cache use.

The server remains authoritative. Remote assistance is disabled by default;
trusted raw-seed mode still explicitly discloses the seed. The separate v3
transcript fixture still accepts only public seed 8675309 and keeps its shared
persistent 100,000-entry disclosure budget. General protocol CURRENT stays 2.

## Limits and warnings

- Raw runtime settings: timeout 10,000 ms, global capacity 8, validation 8 cells,
  cache 0, prediction false. Six other raw jobs time out and fall back; expired
  responses and a tick-delay warning are recorded.
- The successful fixture simultaneous run also has three later timeouts and
  one unchanged-budget admission rejection. These are not remote successes.
- Offline-profile HTTP 401, Realms errors, offline-server/digest warnings and
  JDK native-access/Unsafe warnings remain in logs. Logs are not error-free.
- No speedup, long-session heap-retention, eight-player runtime coverage,
  arbitrary multiplayer population, hostile-server safety, other-dimension
  support or private-seed confidentiality is established.
- Final checks on 2026-09-14 found zero dedicated remote Java processes, zero
  local test clients and zero test-port listeners on both PCs.

Alpha.1's tag, release and five assets remain unchanged. Alpha.2 is a new
prerelease with its own JARs, English/Japanese installation notes and checksums.
