# Alpha.4 verification — Minecraft 26.3

Version `0.1.0-alpha.4+mc26.3` adds separate Fabric, Forge and NeoForge builds
for Java 25 / Minecraft 26.3. It is a prerelease for disposable worlds and
trusted participants. Remote assistance remains disabled by default and the
trusted route discloses the raw world seed only after a separate explicit
choice. The 26.2 public-seed transcript fixture is not included in 26.3.

Forge `B9D3159F8D26BE7D8EDBF3F126E447BE6099CD64C85995CE0F622F9C937E4937`,

The release `SHA256SUMS.txt` lists the exact bytes of all attached files.
All builds used JDK 25.0.4. Vanilla Overworld, Nether and End are the tested
terrain scope; custom generators and mod-added dimensions are not covered.

## Selected verification

- Fabric, Forge and NeoForge development-runtime assisted/vanilla comparisons
  matched all shared NOISE digests across Overworld, Nether and End. Counts and
  limitations are recorded in `docs/PORT_26_3.md` and `docs/TEST_RESULTS_LATEST.md`.
- Installed distribution JAR Overworld comparisons matched 941 shared digests
  for Fabric, 816 for Forge, and 1,628 for NeoForge, including every
  remotely applied result in each comparison.
- Fabric's two-PC installed-JAR two-owner comparison passed on an earlier
  alpha.4 candidate JAR, and exact final-candidate Forge and NeoForge
  installed-JAR sessions each registered two distinct owners and applied
  remote results for both. The latter native sessions warmed owners in sequence
  while both stayed connected; they are not proof of overlapping in-flight jobs.
- Fabric and NeoForge settings screens passed targeted visual smoke checks.
  Forge shares the settings implementation, but the development-client screen
  smoke did not complete; its menu path has not been established by this test.
- Selected server policy/permission and Forge fragment-assembler unit tests
  passed on the development branch. The 26.3 public-seed fixture is unavailable.
- One matched 26.3 Fabric Overworld performance pair completed with three
  measured repeats per route. Median throughput was 69.47 tasks/s for normal
  generation and 67.95 tasks/s with assistance under the selected profile.
  Analysis reported `COMPLETE`, zero issues, and safe cleanup under
  `test-artifacts/validation-matrix-20260926-170015-863/`. This run used a
  temporary settings-smoke diagnostic build (SHA-256 `0BB2B7647C473EDD94A2143CC9EBDD05EF02AD2F4402CB4407B3EDAAF5FA838A`);
  the final Fabric JAR was rebuilt after reverting that diagnostic and returned
  to its previously verified hash. This descriptive measurement does not
  establish a gain or generalize to other conditions.

The first installed-client two-owner NeoForge and Fabric performance attempts
failed during resource loading with native Windows `0xC0000005`. The isolated
26.3 client launcher omitted Minecraft's official
`-XX:StackShadowPages=32` JVM option. After restoring this option, an exact
NeoForge two-owner session passed; the failed attempts remain in
`test-artifacts/` and are not silently counted as successes. A no-MOD remote
NeoForge control had reproduced the same native failure before the launch fix.

This selected validation does not prove a performance gain, long-session or
hostile-server safety, confidentiality for private seeds, or compatibility with
arbitrary mods and datapacks. Offline authentication/Realms errors remain in
the isolated client logs. The 26.2 alpha.3 release and its evidence remain
separate and immutable.
