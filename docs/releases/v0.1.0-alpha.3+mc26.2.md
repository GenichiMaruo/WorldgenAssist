# Worldgen Assist 0.1.0-alpha.3 — Minecraft 26.2

## 日本語

信頼できる参加者のクライアントが、それぞれ本人の新規地形生成を同時に支援する
実験的プレリリースです。trusted raw-seed経路の対象を vanilla の Overworld・
Nether・End に広げ、**設定 → WorldgenAssist** にゲーム内設定画面を追加しました。
クライアントの参加設定は再接続後、サーバー方針は再起動後に反映されます。
リモートからサーバー方針を変更できるのは管理者だけです。

- Minecraft Java Edition **26.2 / Fabric Loader 0.19.3 / Fabric API
  0.156.0+26.2 / Java 25**（検証JDK 25.0.4）。サーバーと参加する
  クライアントに同じ `worldgen-assist-0.1.0-alpha.3+mc26.2.jar` を入れてください。
  `-sources.jar` は導入用ではありません。
- **リモート支援は既定で無効**。trusted raw-seed経路は別の明示設定でシードを
  クライアントに開示します。transcriptフィクスチャは公開シード **8675309のみ**。
  非公開シードの秘匿性と公開サーバーでの安全性は未解決です。
- 3組の選択した全ディメンション正しさ検証では、共有NOISEダイジェスト
  **4,284個**が一致。264テスト/58スイートのチェックポイント後、最終JARの
  設定修正は対象を絞ったテストとビルドで確認しました。全テストやゲーム内での
  接続済み設定画面操作は最終JARで再実行していません。
- 12組の性能測定では、**すべて支援ありの処理量が通常生成を下回りました**。
  高速化は実証していません。測定JARと最終JARの差は設定関連クラスのみです。
  通常生成サーバーの終了が時折失敗し、検証ログにはオフライン認証・Realms
  エラーもあります。

添付の日英導入案内と `SHA256SUMS.txt` を確認してください。MOD追加ディメンション、
カスタムジェネレーター、大規模な人数や長時間運用は保証しません。

## English

This experimental prerelease lets trusted players' clients concurrently assist
their own eligible new terrain. The trusted raw-seed route now covers vanilla
Overworld, Nether and End. **Options → WorldgenAssist** opens the in-game
settings. Client participation applies on reconnect; saved server policy needs
a server restart and remote edits require administrator permission.

- Requires **Minecraft Java Edition 26.2, Fabric Loader 0.19.3, Fabric API
  0.156.0+26.2 and Java 25** (verified with JDK 25.0.4). Install the same
  `worldgen-assist-0.1.0-alpha.3+mc26.2.jar` on server and participating clients.
  The sources JAR is for developers.
- **Remote assistance is off by default.** Trusted raw-seed mode explicitly
  discloses the seed to clients; the separate transcript fixture accepts only
  public seed **8675309**. Private-seed confidentiality and hostile-server
  safety remain unresolved.
- Three selected all-dimension correctness pairs matched **4,284** shared
  NOISE digests. After a 264-test/58-suite checkpoint, final-JAR settings fixes
  passed focused tests and a build. The full suite and connected settings-menu
  exchange were not rerun on the final JAR.
- Assisted throughput was **lower in all twelve measured conditions**. No
  speedup is demonstrated. The measured and final JARs differ only in settings
  classes. An intermittent vanilla server shutdown and offline authentication/
  Realms errors remain in the evidence logs.

Use the attached English/Japanese installation notes and `SHA256SUMS.txt`.
Mod-added dimensions, custom generators, large groups and long-running use are
outside verified scope.
