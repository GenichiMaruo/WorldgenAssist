# Worldgen Assist 0.1.0-alpha.2 — Minecraft 26.2

## 日本語

各プレイヤーが、自分に必要な地形の計算を同時に支援できるようになりました。
サーバーが最終的な生成を管理し、各クライアントには本人の表示範囲内の仕事を
割り当てます。既定の上限は全体8ジョブ、1人1ジョブです。切断・再接続・結果の
隔離をプレイヤーごとに扱い、処理できない仕事は通常生成へ戻ります。

- Minecraft Java Edition **26.2 / Fabric Loader 0.19.3 / Fabric API 0.156.0+26.2 / Java 25**（検証JDK: 25.0.4）。
- サーバーと参加する全クライアントを alpha.2 に揃えてください。導入するのは
  `worldgen-assist-0.1.0-alpha.2+mc26.2.jar` です。`-sources.jar` は開発者向けです。
- **246テスト / 52スイート、失敗・エラー・スキップ0**。2人の同時支援を両経路で
  確認し、通常生成との共有NOISEダイジェストは公開フィクスチャ588個、trusted-raw
  382個が一致。開発用結果保留を片方に使った切断試験でも406個が一致しました。
- **リモート支援は既定で無効**です。trusted raw-seed経路はシードを開示します。
  別経路のtranscriptフィクスチャは公開シード **8675309のみ**です。
- タイムアウトやオフライン認証・Realmsエラーは検証ログに残っています。
  **高速化・非公開シードの秘匿性・一般の公開サーバーでの安全性は実証していません。**

添付の日英導入案内と `SHA256SUMS.txt` を確認してください。alpha.1 の添付物や
タグは保持しています。今回も安定版ではなく、条件を限定した試用向けのプレリリースです。

## English

Each player's client can now assist its own terrain generation concurrently.
The server remains authoritative and assigns direct work only within that
owner's view. The default limit is eight global jobs and one per owner.
Disconnects, replacement connections and quarantined results are owner-specific;
unavailable work falls back to normal server generation.

- Requires **Minecraft Java Edition 26.2, Fabric Loader 0.19.3, Fabric API
  0.156.0+26.2 and Java 25** (tested with JDK 25.0.4).
- Use alpha.2 on the server and all participating clients. Install
  `worldgen-assist-0.1.0-alpha.2+mc26.2.jar`; the sources JAR is for developers.
- **246 tests / 52 suites**, zero failures/errors/skips. Two installed clients
  pass concurrent assistance in both routes, matching **588** public-fixture
  and **382** trusted-raw shared NOISE digests against independent vanilla.
  An owner-disconnect probe with development-only withholding on one client
  also passes, matching **406** shared digests.
- **Remote assistance remains disabled by default.** Trusted raw-seed mode
  reveals the seed; the separate transcript fixture accepts public seed
  **8675309 only**. General protocol remains 2.
- Timeouts and offline-profile/Realms errors remain in the logs. **Speedup,
  private-seed confidentiality and general public-server safety are not proven.**

Read the attached installation notes and verify `SHA256SUMS.txt`. This is an
experimental prerelease for controlled trials. Alpha.1's tag and assets remain
unchanged.
