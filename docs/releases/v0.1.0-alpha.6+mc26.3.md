# Worldgen Assist 0.1.0-alpha.6 — Minecraft 26.3

## 日本語

クライアントの計算をサーバーの新規地形生成へ活用する改善をまとめたアルファ版です。
サーバーが担当範囲と最終ワールド状態を管理し、各参加者が本人の地形密度計算を支援します。

- Minecraft Java Edition **26.3 / Java25**。Fabric Loader **0.19.5** + Fabric
  API **0.161.0+26.3**、Forge **66.0.3**、NeoForge **26.3.0.13-beta** の
  各導入用JARとソースJARを配布します。`-sources.jar`は導入用ではありません。
- **サーバーと参加クライアントをalpha.6へ同時更新してください。** 通信プロトコルは
  **6**になり、alpha.5（プロトコル4）とは支援通信できません。
- 対応するOverworld生成では補間前の5種類の地形グリッドと表面データを返し、
  大きな完成密度データの転送を減らします。ブロック配置・装飾・保存などはサーバーが行います。
- 未生成チャンクの早期予告、生成開始後の不要な依頼・結果の取り消し、検証処理の
  生成コンテキスト再利用を追加し、計算・管理の無駄を減らします。
- 任意のサーバー並列生成、上限付きの依頼枠拡大、返答待ちと独立した別チャンクの
  処理を重ねる実験設定を提供します。上限・本人・通信世代・期限・通常生成への復帰を維持します。
- Fabricクライアントは通信受信から上限付き計算キューへ依頼を渡し、描画スレッドでの
  受付待ちを減らします。Forge／NeoForgeは既存の受信経路を維持します。
- 対象を絞った一括検証と32チャンク全範囲の測定スクリプト、CPU診断を追加しました。

### 性能と検証

別PCのサーバーを2論理CPU・Java認識CPU数2へ制限し、2人接続で測定した3回の中央値です。
**両条件とも同じサーバー並列生成方式**で、支援の有無を比較しています。
下表は通常の既定値ではなく、添付導入案内の非同期待機・依頼枠拡大を使った実験設定です。

| 距離32 | 支援なし | 支援あり | 変化 |
| --- | ---: | ---: | ---: |
| チャンク完成（FULL） | 298.62秒 | 293.00秒 | **1.88%短縮** |
| 両クライアントへの到着 | 314.19秒 | 309.66秒 | **1.44%短縮** |
| サーバーCPU時間 | 624.86秒 | 583.50秒 | **6.62%減少** |
| tick処理時間p95 | 49.91ms | 51.72ms | **3.64%増加** |

完成・受信は3回中2回改善、CPU時間は3回とも減少しました。各回10,658件の地形生成と
各人3,461件の全件受信を確認しました。距離10では完成6.66%・受信7.20%・CPU9.65%減少。
ただし実行順固定の3回比較で、**安定した高速化や一般的な効果は未確立**です。
alpha.5との直接比較でもありません。受信は描画完了を含みません。
距離32の最大200ms待機から通常生成への復帰は158/225/173件あり、依頼自体の期限切れとは区別しています。

最新のFabric・Overworld・2人接続の一致確認で、**共通1,813チャンクの不一致0件**、
両人の非同期待機後のグリッド利用を確認しました。3ローダーの配布JARは検証済みdev.12と
版情報のみ異なり、コード・Mixin・その他のリソース、ソースJARの内容は一致します。
元の候補の検証記録を配布版の新規実行として扱っていません。
Forge／NeoForgeの変更後の実行、長時間運用、任意のMODとの互換性は未確認です。

**リモート支援は既定で無効**です。有効化にはワールドシードを参加者へ開示する別の
明示設定が必要です。信頼できる参加者の使い捨て検証ワールド向けで、シード秘匿性は未解決です。
抜き取り検証は悪意ある結果のすべてを認証するものではありません。
任意の独自生成器・クライアントにないノイズ定義、26.2の公開シード専用経路は対象外です。
添付の日英導入案内・検証記録・`SHA256SUMS.txt`を確認してください。

## English

This alpha packages client-assisted terrain improvements while retaining
server-owned assignment, bounded validation, local fallback and final world state.

- Requires **Minecraft26.3 / Java25**. Separate installable/source JARs for
  Fabric **0.19.5** + API **0.161.0+26.3**, Forge **66.0.3** and NeoForge
  **26.3.0.13-beta**. Update server and participating clients together:
  **protocol6 is incompatible with alpha.5 protocol4**.
- Eligible Overworld work returns five pre-interpolation terrain grids and
  surface intermediates. Adds earlier generation hints, obsolete-result
  retirement, private cached validation contexts and bounded larger windows.
- Optional cooperative server generation and asynchronous demand waiting let
  independent work continue. Owner/epoch/deadline/cancellation limits remain.
  Fabric clients admit requests from the network into bounded worker queues;
  native loaders retain their existing request route.
- Adds focused sequential gates, full-distance32 comparisons and CPU diagnostics.

With an **explicit experimental profile**, a separate server restricted to two
logical CPUs/JVM2 and two clients at distance32 showed median FULL
**298.62s →293.00s (-1.88%)**, receipt **314.19s →309.66s (-1.44%)**, server
CPU **624.86s →583.50s (-6.62%)**, tick p95 **49.91ms →51.72ms (+3.64%)**.
Both modes used the same cooperative scheduler. Completion/receipt improved
two of three repeats, CPU all three; **stable/general speedup is not established**.
This fixed-order comparison is not alpha.5 versus alpha.6. Receipt excludes
render completion. Short demand waits fell back158/225/173 times at distance32.

Latest Fabric Overworld two-owner correctness matched **1,813 shared NOISE
digests**, both owners actually awaited and consumed grids. All final JAR
entries except exact version metadata match the tested dev.12 candidates;
all source archive entries match. Runtime evidence retains original hashes.
Latest native runtime, long sessions and arbitrary mod compatibility are unverified.

Remote assistance stays **off by default**; measured cooperative/wide/
asynchronous settings also remain explicit experiments. Enabling trusted raw-seed
mode discloses the seed to participants. Private-seed confidentiality remains
unresolved; sampled validation does not authenticate all hostile results.
Use trusted disposable test worlds. Arbitrary custom generators and client-unavailable
registries remain unsupported; the26.2 public-seed fixture is not included.
Read the attached installation guides, verification record and checksums.
