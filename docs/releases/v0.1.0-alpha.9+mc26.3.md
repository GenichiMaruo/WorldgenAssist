# Worldgen Assist 0.1.0-alpha.9 — Minecraft 26.3

## 日本語

Forge／NeoForgeの計算依頼受付を改善する任意機能と、その検証結果をまとめたアルファ版です。

- 計算依頼を、描画などを扱うクライアントの主処理を待たず、既存の上限付き計算担当へ渡せます。
- 接続ごとに依頼の有効性を管理します。ディメンション移動・切断・通信切替で古い依頼と返答を
  失効させ、移動後の通常処理が完了してから新しい依頼を受け付けます。遅れて届く旧接続の
  処理や、連続して受信した移動通知も対象です。
- ネイティブ版に最大4件の依頼まとめ送りを追加しました。各依頼の所有者・期限・取り消し・
  検証は従来どおりです。
- **両機能は既定で無効**です。支援・シード開示・完全地形・別クライアント照合も明示設定です。
  地形生成、検証量、サーバーの最終権限を変更していません。仮描画はありません。

### 成果と限界

弱いi7-7700Kサーバーと強いi7-12700K上の2クライアント、距離32で、
同じ候補JAR・両条件とも支援あり・まとめ送り無効・各条件ウォームアップ1回／同じ3領域を
通常受付→直接受付の順に比較しました。同じ回の比率の中央値です。

| 直接受付ONの変化 | Forge | NeoForge |
| --- | ---: | ---: |
| 往復待ち時間 | **-21.28%** | **-17.26%** |
| チャンク完成（FULL） | -2.92% | -0.20% |
| 両クライアントへの受信 | -3.68% | -1.26% |
| サーバーCPU時間 | **+9.99%** | -3.43% |
| tick p95 | +3.16% | -0.58% |

往復待ち時間は両ローダーの全3回で減少しました。完成はForgeの3回／NeoForgeの2回で改善。
ただし生成全体の効果は小さく、ForgeのCPU負担は増加しています。逆順の比較は未実施で、
大幅な高速化、alpha.8との直接比較、支援そのもののON/OFF効果や一般的な保証は示していません。
受信には描画完了を含みません。別のまとめ送り比較では速度向上を確認できませんでした。

新しい対象3テストと3ローダービルドを一括実行して成功。
両ネイティブ版でそれぞれ25段階の確認を通過し、着地・採掘・設置・移動・再接続と
停止後の保存を確認しました。8人分の保存状態はHealth20・死亡／ダメージ統計0、
設置したCOBBLESTONEも保持。4条件それぞれで50内部／162周辺チャンク、
10,649,600照明値の不一致0です。新しいテスト用MODは配布物に含めません。

Fabricは従来の動作を維持し、今回の任意受付は登録しません。変更していない生成処理の
3ローダー各882座標の一致と、Fabricでの従来の速度・通常プレイ検証は元のJARの証跡を保持します。
以前の約20.93%短縮を今回の受付変更による成果として扱っていません。

### 導入

Minecraft **26.3 / Java25**、Fabric **0.19.5 + API0.161.0+26.3**、
Forge **66.0.3**、NeoForge **26.3.0.13-beta**の対応JARを使用します。
**通信プロトコル14／ネイティブ通信6**。サーバーと参加クライアントを同時に更新してください。

任意の直接受付はForge／NeoForge各クライアントのJava引数
`-Dworldgen_assist.native.client_request_ingress=true` で有効にします。
まとめ送りはサーバーの `-Dworldgen_assist.native.request_batching=true` という別の実験です。
詳しい支援設定は添付のINSTALL.ja.mdを参照してください。

配布版は検証済みalpha.9-dev.2と版情報だけが異なることを照合しました。
添付の検証記録とSHA256SUMS.txtに正確な証跡・配布ハッシュを記載しています。
ソースJARは導入用ではありません。

信頼できる参加者の試用向けです。シード秘匿・共謀対策は未解決。
完全地形は対象条件を満たすvanilla Overworldに限定され、任意の独自生成器は対象外です。
サーバー再起動、継続探索・戦闘・危険な環境・長時間運用は未検証のため、**アルファを継続**します。

## English

connection-bound revocation before respawn/disconnect/protocol changes, and safe
MAIN restoration after original respawn completion. Old callbacks never revive;
queued consecutive respawns retain suspension. Native bounded 1..4-job batching
is a separate switch. Both switches default false; remote assistance and seed
disclosure remain explicit. Generation, audit amounts and server authority remain.

Weak i7-7700K server/two clients on a stronger i7-12700K PC/view32, same dev.2 JAR,
both assisted, batching disabled, one excluded warmup/three matched regions,
MAIN first. Median matched NETWORK/MAIN ratios: Forge/NeoForge job RTT
**-21.28%/-17.26%**, FULL **-2.92%/-0.20%**, receipt **-3.68%/-1.26%**,
server CPU **+9.99%/-3.43%**, tick p95 **+3.16%/-0.58%**.
All RTT repeats lower; FULL3/3 versus2/3 faster. Gains are small and Forge CPU
rises. No opposite-order reproducibility, alpha.8 comparison, general assistance
ON/OFF proof or universal/substantial acceleration. Receipt excludes rendering.
Separate batching comparison demonstrated no speed gain.

Exactly three affected methods/three builds pass in one sequential batch.
Both native loaders pass all25 lifetime/gameplay/stopped-save/light steps;
all8 saved players Health20/deaths0/damage0 with exact placed COBBLESTONE.
Each of four own-light cases compares50 interior/162 halo chunks/10,649,600
values with zero differences. Probe MODs/worlds/logs are excluded from assets.
Fabric registers no new native hooks. Prior unchanged generation three-loader882
and Fabric performance/gameplay evidence retain original identities; the old
20.93% figure is not attributed to this request-admission change.

Requires Minecraft26.3/Java25 with Fabric0.19.5 + API0.161.0+26.3,
Forge66.0.3 or NeoForge26.3.0.13-beta. **Protocol14/native6: update both sides.**
Optional client Java argument `-Dworldgen_assist.native.client_request_ingress=true`

also defaults false. Read INSTALL.md and the verification/checksums.
Packaging compares every candidate/release archive entry: version metadata only;

Trusted participants/eligible vanilla Overworld complete terrain only.
Seed secrecy, collusion resistance, arbitrary generators, server restart,
