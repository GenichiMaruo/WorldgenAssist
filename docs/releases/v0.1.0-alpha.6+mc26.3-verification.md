profile: owner16/global32/client16, cache128, prediction enabled, eight secret
checks, lookahead0, ready_surface_only=false, base wait100ms/max200ms, job

initiating PC, heap4GB each, maxFPS30. Server/client distances matched;
simulation-distance3. Seed8675309 and measured coordinates/work were identical.

## Scope and remaining limits

Protocol6 is incompatible with alpha.5 protocol4. Install matching versions
on the server and participants. Density intermediates only: final blocks,
features, lighting, saves and gameplay remain on the server. Remote assistance
is off by default; cooperative/wide/asynchronous settings also remain explicit
experiments. See [English installation](../INSTALL.md#measured-experimental-profile)
and [日本語の実験設定](../INSTALL.ja.md#測定した実験設定).

Trusted raw-seed mode discloses the seed. Private-seed confidentiality remains
unresolved; sampled verification is not protection against all hostile data.
Arbitrary custom generators/client-unavailable registries remain unsupported.
The26.2 public-seed transcript fixture is absent from26.3. Native runtime,
long sessions and arbitrary mod/datapack combinations remain unverified.
