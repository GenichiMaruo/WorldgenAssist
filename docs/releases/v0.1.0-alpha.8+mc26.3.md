# Worldgen Assist 0.1.0-alpha.8 — Minecraft 26.3

## 日本語

弱いサーバーと強いクライアントでの地形生成を改善した、新しいアルファ版です。

- 既存の生成依頼・依存関係を早く観測し、上限付きの依頼索引と結果キャッシュで待機を減らしました。
- サーバー上のFEATURESと照明初期化の順序・領域所有を管理し、重ならない生成を並列実行できます。
  ステージの本体終了後も、元の適用・状態公開が終わるまで必要な保護を保持します。
- 完全地形の反映で元のパレット処理を再利用し、バイオーム入力の再計算を減らしました。
  実際の依頼に、サーバーが完了した3×3 BIOMESの不変データを渡せます。
- バイオームだけが異なるクライアント結果は、地形全体が一致する場合に両候補を保持し、
  反映直前のサーバーの入力と完全一致する元の候補を選びます。合わなければ通常生成へ戻ります。
- 明示設定、別クライアント照合、秘密のサーバー監査、所有者・世代・期限・範囲・反映前検査を維持します。
  支援と新機能は既定で無効です。仮描画はありません。

### 測定結果と検証範囲

弱いi7-7700Kサーバーと、強いi7-12700K上の2クライアント、距離32、
各条件ウォームアップ1回・測定3回で、順序を逆にして比較しました。
支援なし／ありで同じJAR、同じcooperative NOISE・parallel FEATURESを使用しています。

| 指標 | 支援ありの変化 |
| --- | ---: |
| チャンク完成（FULL） | **20.93%短縮** |
| 両クライアントへの受信 | **21.20%短縮** |
| サーバーCPU時間 | **19.63%減少** |
| tick処理時間p95 | **8.95%増加** |

同じ領域ごとの6組の比率の中央値です。完成・受信・CPUは全6組で改善し、
tick p95は全6組で悪化しました。6組は同じ3座標を再利用しています。
各回10,658タスク、各人3,461必須チャンク受信を確認。受信は描画完了ではありません。
alpha.7との直接比較、新入力変更だけの効果、他環境での保証にはしていません。

最新の対象4テスト・3ビルドが一括で成功。Fabric／Forge／NeoForgeそれぞれ
882必須座標で地形・装飾・保存構造物・照明の不一致0でした。
Fabricの通常サバイバル検証も支援なし／あり・両参加者で着地、採掘、設置、再接続を通過。
停止後の4人分の保存状態はHealth20・死亡／ダメージ統計0、設置ブロックを保存しました。
実際の操作地点周辺で各条件50内部／162周辺チャンク、10,649,600照明値が一致しました。

配布版は検証済みdev.23と版情報のみ異なることを確認しました。
元の実行証跡は元のJARに紐づけ、公開版を新規実行したとは扱いません。
詳細・配布ハッシュは添付の検証記録に記載しています。

### 導入と制限

Minecraft **26.3 / Java25**、Fabric **0.19.5 + API0.161.0+26.3**、
Forge **66.0.3**、NeoForge **26.3.0.13-beta**の対応JARを使います。
**通信プロトコル14／ネイティブ通信5**のため、サーバーと参加者を同時に更新してください。
添付のINSTALL.md／INSTALL.ja.mdの実験設定が必要です。

シード開示を明示的に選ぶ信頼できる参加者向けです。秘匿・共謀への耐性は未解決。
完全地形は対応するvanilla Overworldに限定され、任意の独自生成器は対象外です。
ネイティブ版の通常プレイ、サーバー再起動、継続探索・戦闘・危険な環境・長時間運用は
未検証で、**β版にはしていません**。既存の失敗記録は保持しています。
ソースJARは導入用ではありません。ワールドと検証用ログは添付していません。
